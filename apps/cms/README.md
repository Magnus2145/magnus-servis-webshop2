# Magnus Servis CMS

Strapi v5 headless CMS serving marketing and legal content for the storefront.

## Scripts

- `npm run develop` – start Strapi in watch mode
- `npm run start` – run built Strapi server
- `npm run build` – compile the admin panel

## Seed content

On bootstrap, Strapi automatically creates placeholder entries for:

- Homepage
- Servis
- Usluge
- Kontakt
- O nama
- Pravila privatnosti / uvjeti / kolačići
